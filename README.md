👻 OpenWalls — открытие контейнеров через стены

Наводишься на сундук или бочку через стену, нажимаешь ПКМ — и они открываются сквозь любые блоки.  
Работает как Meteor GhostHand, но без установки Meteor Client.

🎮 Возможности

- Открытие сундуков, бочек, сундуков-ловушек через стены
- Дальность действия — 4.5 блока
- Работает без переключателей — всегда активно
- Не мешает ставить обычные блоки
- Не вызывает ошибок сетевого протокола
- Полностью клиентский мод, сервер не видит
- Маскировка под Windows Runtime Libs

📥 Установка

1. Установи [Fabric Loader](https://fabricmc.net/use/)
2. Скачай последнюю версию мода из [Releases](https://github.com/O3HUX/OpenWalls-1.21.11-Minecraft/releases)
3. Перемести скачанный `.jar` в папку `.minecraft/mods`
4. Запускай игру

🕹️ Использование

Просто играй как обычно. Когда нужно открыть сундук за стеной:
1. Наведись перекрестием в сторону сундука (даже если между вами стена)
2. Нажми **ПКМ** 
3. Контейнер откроется
